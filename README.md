# Coworking Booking Platform (Микро-SaaS)

Платформа для бронирования рабочих мест с интерактивной картой и аналитикой в реальном времени.

## Быстрый старт (Docker)

Для сборки и запуска всего окружения в локальном режиме разработки выполните команду:

```bash
docker-compose up --build
```

Это действие запустит:
- **PostgreSQL (v16)** на порту `5432`
- **Redis (latest)** на порту `6379`
- **Backend (Node.js + TS)** на порту `5000` (с автоматическим ожиданием готовности БД, выполнением миграций/сидов и автоперезагрузкой при изменении кода)
- **Frontend (React + Vite + TS)** на порту `5173` (с поддержкой горячей перезагрузки HMR)

### Как остановить приложение

Чтобы остановить и остановить контейнеры с сохранением данных:

```bash
docker-compose down
```

Для удаления всех данных в БД и Redis (очистка volume):

```bash
docker-compose down -v
```
