# Отчет по выполнению задачи: Развертывание и реализация Frontend-приложения (04-frontend-init)

Мы успешно инициализировали, настроили и реализовали клиентскую часть платформы бронирования коворкингов на базе React, TypeScript, Tailwind CSS, Zustand, TanStack Query и react-router-dom.

---

## 🛠 Выполненные действия и технологии

### 1. Конфигурация сборки и темы (Tailwind CSS v4 + PostCSS)
* Установили и настроили `@tailwindcss/postcss` и `autoprefixer` для совместимости сборщика Vite с Tailwind CSS v4.
* **[index.css](file:///d:/Job/Resume/booking-react-nodejs/frontend/src/index.css):** Написали кросс-версионный Vanilla CSS для стилизации фона `body` и поддержки темного режима (Dark Mode).
* Настроили `tailwind.config.js` для поддержки кастомной цветовой гаммы в дизайне.

### 2. Клиентская инфраструктура (Сессии и Запросы к API)
* **[api/client.ts](file:///d:/Job/Resume/booking-react-nodejs/frontend/src/api/client.ts):** Создали API-клиент на базе Axios. Добавили перехватчик запросов для автоматического прикрепления `Authorization: Bearer <token>` и перехватчик ответов для бесшовного обновления сессии (автоматический запрос `/auth/refresh` при получении 401 ошибки и повтор исходного запроса).
* **[Zustand Stores](file:///d:/Job/Resume/booking-react-nodejs/frontend/src/stores/):**
  * `authStore`: Отслеживает статус авторизации, выполняет вход/выход, регистрирует новых пользователей и восстанавливает сессию при перезагрузке страницы, считывая JWT-токен.
  * `bookingStore`: Управляет активным выбором пользователя (офис, рабочее место, даты бронирования).

### 3. Защита маршрутов и Шаблоны (Layouts & Guards)
* **[guards/](file:///d:/Job/Resume/booking-react-nodejs/frontend/src/components/guards/):**
  * `PrivateRoute`: Блокирует гостевой доступ к панели управления и строго ограничивает доступ к путям `/admin` только для пользователей с ролью `admin`.
  * `PublicRoute`: Перенаправляет уже авторизованных пользователей с форм входа/регистрации сразу в панель управления.
* **[layouts/](file:///d:/Job/Resume/booking-react-nodejs/frontend/src/layouts/):**
  * `AuthLayout`: Изящный центрированный шаблон с эффектом стеклянного морфизма для страниц авторизации.
  * `DashboardLayout`: Адаптивный шаблон панели управления с боковым меню, переключателем темного режима, карточкой профиля и кнопкой выхода.

### 4. Реализованные Страницы
* **Авторизация:** Полноценный цикл входа, регистрации (с выводом сообщения о необходимости верификации), сброса и восстановления пароля по токену, а также активации аккаунта.
* **Кабинет Пользователя:**
  * Позволяет выбрать даты и коворкинг-зону (офис).
  * Интерактивная карта выбора рабочих мест.
  * Форма бронирования (интеграция с TanStack Query).
  * Список активных броней с возможностью мгновенного удаления (отмены).
  * Вывод анимированных всплывающих сообщений (`react-hot-toast`) об успехе или о возникновении конфликта бронирования (overbooking).
* **Кабинет Администратора:**
  * Интегрированы вкладки с подробными таблицами пользователей, офисов, рабочих мест и бронирований.
  * Возможность создания новых офисов и мест с помощью всплывающих модальных окон.
  * Функционал удаления любых ресурсов.
