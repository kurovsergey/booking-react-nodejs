# Docker init

# Target: Cоздать базовую конфигурацию Docker для проекта. 

# Promt:

## Добавить базовый Dockerfile для backend (Node.js + TypeScript) с установкой зависимостей и запуском приложения.*

## Добавить базовый Dockerfile для frontend (React + TypeScript) с установкой зависимостей и запуском в режиме разработки.

## Докер-контейнеры: 
    - Создать docker-compose.yml для запуска:
    - PostgreSQL (версия 16 или выше)
    - Redis (последняя стабильная версия)
    - Docker-контейнер с Node.js для backend
    - Docker-контейнер с React для frontend

## Docker-контейнеры должны быть настроены на автоматическую перезагрузку при сбоях.

## Сеть:
    - Общая сеть для всех контейнеров с понятными названиями (например, coworking-net).
    - База данных и Redis должны быть доступны внутри сети и для внешнего подключения.

## Добавить в docker-compose.yml секцию volumes для постоянного хранения данных PostgreSQL и Redis.

## Включить в Docker-контейнер backend скрипты для автоматического запуска миграций базы данных и наполнения ее тестовыми данными (сидами).

## Результат:
    - Рабочий docker-compose.yml, который позволяет одной командой docker-compose up --build запустить все сервисы в локальном окружении.
    - Четкие инструкции в README.md о том, как запустить и остановить приложение.
